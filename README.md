# Purpose 
Reverse engineer raw python or flask code to generate equivalent APIs in other languages.

## Goals
1. Generate API endpoints and json payloads from existing python code.
2. Run Flatbuffers converter on the json outputs.
3. Scrape websites known to have the best, complete examples of Flask or Python REST boilerplate.

## Gains

We get to recylce our code without reinventing the wheel.  I should be able to take Python and get a C# API auto-built and ready to run.
